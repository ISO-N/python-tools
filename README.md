# Python 工具箱

一个基于 **PyQt6** 的本地桌面工具箱，把常用的 PDF、图片与文件批处理操作收进一个窗口。
纯本地运行，所有处理都在你的机器上完成，不上传任何数据。

## 快速开始

项目使用 [uv](https://docs.astral.sh/uv/) 管理依赖：

```bash
uv sync          # 安装依赖
uv run main.py   # 启动工具箱
```

依赖 Python 3.12（版本由 `.python-version` 固定）。

## 功能一览

工具箱共 13 个工具，按用途分组如下。

### PDF 处理

| 工具 | 说明 |
| --- | --- |
| PDF 转图片 | 逐页渲染为 PNG / JPEG，支持页码范围与 DPI 设置 |
| 图片合成 PDF | 把图片文件夹按自然页码顺序合成为 PDF，支持递归子目录 |
| PDF 合并 / 拆分 | 按顺序合并多个 PDF；或按每页、每 N 页、自定义范围拆分 |
| PDF 压缩 | 无损清理冗余数据，或把页面重编码为图片以大幅压缩扫描件 |
| PDF 页码 / 书签 / 水印 | 批量添加页脚页码、按章节 JSON 生成目录书签、绘制中文文字水印 |

### 图片处理

| 工具 | 说明 |
| --- | --- |
| 图片批量转换 | 批量转 JPEG / PNG / WebP，支持长边或百分比缩放，保留目录结构 |
| 图片长图 / 拼图 | 按自然顺序拼接为纵向长图或网格拼图，可设宽度、列数、间距与背景色 |
| 图片批量水印 | 添加中文文字水印，支持九宫格位置或平铺、透明度、颜色与角度 |
| 图片按页码归档 | 按 JSON 配置的章节起始页码把图片移入对应子文件夹，支持预览与撤销 |

### 文件整理

| 工具 | 说明 |
| --- | --- |
| 文件批量重命名 | 查找替换、序号重排、加前后缀；表格预览、冲突检测、两阶段执行并支持撤销 |
| 重复文件查找 | 按大小、前缀哈希与完整哈希查找内容相同的文件；移入隔离区而非删除 |
| 文件批量整理 | 按扩展名、修改日期或文件大类整理文件，支持递归、冲突处理与撤销 |
| EPUB 电子书制作 | 把章节子文件夹中的图片打包为 EPUB 2 电子书，支持封面、元数据与目录 |

## 特色

- **可撤销**：批量改名、整理、归档、去重等破坏性操作都采用「预览 → 确认 → 执行」两阶段流程，并保留撤销入口。
- **可取消**：耗时任务在后台线程运行，进度条随时可取消，已完成的部分结果不会丢失。
- **中文友好**：界面字体自动探测（微软雅黑 / Noto Sans CJK 等），文件名按自然顺序排序（`img2` 排在 `img10` 前）。
- **安全写入**：所有输出先写临时文件再原子替换，避免中途失败留下损坏文件。

## 项目结构

```
main.py                 # 应用入口
toolbox/
├── app.py              # 主窗口（左侧工具列表 + 右侧页面）
├── registry.py         # 工具注册表，新增工具在此登记
├── page.py             # 工具页基类
├── ui.py / common.py   # 通用 UI 与工具函数
├── workers.py          # 可取消的后台任务封装
├── fileops.py          # 文件移动与冲突处理
├── images.py           # 图片扫描、方向校正与安全保存
├── pdf_utils.py        # PDF 打开、保存与文字绘制
├── chapters.py         # 章节 JSON 解析
└── tools/              # 13 个工具的具体实现
```

## 新增一个工具

1. 在 `toolbox/tools/` 下新建模块，继承 `ToolPage` 实现界面。
2. 在 `toolbox/registry.py` 中添加一条 `ToolSpec`，在工厂函数内导入页面（延迟导入，避免启动时加载重依赖）。
3. 工具列表会按显示名自动排序，无需手动调整顺序。
